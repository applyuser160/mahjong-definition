## 1. 目的・スコープ

### 1.1 目的

手牌の有効牌探索（`calculate_acceptance`）は、何切る解析や打牌候補の期待値評価の根幹をなすホットパスです。
現状の実装では、手牌に関わらず全34種類の牌について1枚ずつ仮ツモし、毎回 `calculate_shanten_from_counts` をゼロから完全再計算しています。
これにより以下の無駄な計算が発生しています：
1. **全34種×3スーツの LUT 再探索**:
   各仮ツモ候補において、変化した1スーツだけでなく変化していない他の2スーツも毎回 `encode_suit_key` して LUT を引き直している。
2. **特殊形（七対子・国士無双）の重複全走査**:
   七対子（34要素走査）および国士無双（13要素走査）を34候補すべてでフルループ走査している。
3. **自明に進まない孤立牌の無駄な仮ツモ**:
   手牌およびその周辺（$\pm 2$ 以内）に牌が存在しない孤立牌を引いてもシャンテン数が進むことはあり得ない（特殊形の可能性を除く）にもかかわらず、毎回シャンテン計算を行っている。

本改修の目的は：
- 手牌の初期状態（3スーツのキー・`SuitEntry`、字牌集計、七対子集計、国士集計）を事前集計した `ShantenState` を構築し、仮ツモ牌 $i$ に対するシャンテン数変化を **$O(1)$ 差分更新** すること。
- 手牌の牌種分布・特殊形の可能性に応じた **有効牌枝刈りマスク** を導入し、自明に進まない牌の仮ツモをスキップすること。
- 既存の受け入れ牌一覧・残り枚数・シャンテン数計算結果の 100% 同値性を担保すること。

### 1.2 スコープ

**スコープ内:**
- `shanten.rs`: 通常形シャンテン数合成のヘルパー関数 `eval_normal_shanten` の抽出
- `shanten.rs`: 手牌初期状態を保持し仮ツモ後の向聴数を $O(1)$ 差分更新する `ShantenState` 構造体およびメソッドの実装
- `acceptance.rs`: `ShantenState` による差分向聴数計算への置換
- `acceptance.rs`: 自明に進まない牌をスキップする枝刈りマスクの導入
- 合法手牌・全34種仮ツモ候補に対する「差分版 == 従来の完全再計算」プロパティテストの追加
- ベンチマーク `calculate_acceptance` による性能向上の検証

**スコープ外:**
- `calculate_acceptance` の戻り値構造体（`AcceptanceResult`）の変更（後方互換性維持）

## 2. 機能要件 (FR)

### FR-1: 通常形シャンテン計算のヘルパー分離
- `shanten.rs` 内に、3スーツの `[SuitEntry; 3]`、字牌刻子数 `z_melds`、字牌対子数 `z_pairs`、副露数 `open_melds_count` から通常形シャンテン数を算出する純粋ヘルパー関数を定義すること。

### FR-2: シャンテン差分計算状態 (`ShantenState`) の導入
- 元手牌のスーツキー・LUTエントリ、字牌集計、七対子の種類数・対子数、国士無双の么九種類数・対子数を保持する `ShantenState` を提供すること。
- `ShantenState::after_draw(tile_idx)` メソッドにより、該当スーツのみのキー更新（`key + 5^pos`）または字牌/特殊形カウントの $O(1)$ 更新のみで仮ツモ後 `ShantenResult` を算出すること。

### FR-3: 枝刈りロジックの導入
- 元手牌の数牌（萬筒索）について、牌が存在するインデックスの $\pm 2$ 以内の牌、および手牌に存在する字牌を通常形の候補マスクとして設定すること。
- 七対子・国士無双の向聴数が `current_shanten` 以下の場合は、それらの向聴数を進めうる牌（七対子: 新規種・対子化、国士: 么九牌）を候補マスクに追加すること。
- マスク外の牌は仮ツモ・シャンテン判定をスキップすること。

### FR-4: 結果の完全同値性
- 差分更新および枝刈り適用後の `calculate_acceptance` の結果（受け入れ牌の種類・残り枚数・順序）が従来と厳密に一致すること。

---

## 3. 非機能要件 (NFR)

### NFR-1: 性能向上
- `calculate_acceptance` の実行時間を大幅に短縮すること。
- 1候補あたりのシャンテン計算コストを従来の 3スーツ全エンコード・特殊形全走査から $O(1)$ 差分更新へ低減すること。
