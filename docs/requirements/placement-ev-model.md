## 1. 目的・スコープ

### 1.1 目的
麻雀の勝敗は「素点（持ち点そのもの）」だけでなく、半荘終了時の「着順（1位〜4位）に応じた順位点（ウマ・オカ）」によって決定づけられます。
これまでの素点期待値（和了点数ベースのEV）に加え、**各プレイヤーの持ち点・点差・局進行（東場/南場/オーラス）・順位点ルールを考慮した「順位期待値（Placement EV / Pt EV）」モデル**を導入することで、プレイヤーが「トップ目の逃げ切り局消化」「ラス目の打点作り・着順浮上」「オーラスの逆転条件逆算」といった高度な点況判断・押し引き理論を定量的に学習できるようにします。

### 1.2 スコープ

**スコープ内:**
- **点況・ルールモデルの定義**:
  - 4人の持ち点、現在着順、局数（東1局〜南4局オーラス）、本場、供託棒、親番情報。
  - 順位点ルール（ウマ・オカ）の設定（Mリーグ基準 +50/+10/-10/-30、一般ウマ +20/+10/-10/-20、天鳳風ラス回避重視ルール等）。
- **順位期待値（Placement EV）算出**:
  - 各打牌候補による局結果（和了・放銃・横移動・流局）後の点数変動を予測。
  - 残り局数と点差に基づく着順確率分布（1位率〜4位率）を推定し、総合順位Pt期待値を算出。
- **オーラス逆転条件・着落ち防衛条件の自動計算**:
  - ターゲット（上位着順）との点差から、ツモ・直撃・他家出和了に必要な条件（翻・符・打点）を自動計算・提示。
  - 下位からの追撃リスク（放銃許容打点、ツモられ耐性）の算出。
- **点況適応型AI判断・解説生成**:
  - 点況に応じた戦術判断（「トップ目につき速度重視で局を流す」「打点が必要なラス目につき安手を拒否」等）の解説テキスト生成。
- **4人対局モード (`examples/play_with_cpu.rs`) への統合**:
  - プレイヤーのHUDに点差、現在順位EV、最善打牌、逆転条件をリアルタイム表示。

**スコープ外:**
- 牌譜データベースを用いた数百万局のディープニューラルネットワーク学習（本フェーズでは数理モデルとヒューリスティック関数により低レイテンシで正確に算出）。

## 2. 用語定義

| 用語 | 定義 |
|------|------|
| **順位点（ウマ・オカ）** | 半荘終了時に素点とは別に着順に応じて付与されるポイント（例: 1位+50pt、2位+10pt、3位-10pt、4位-30pt）。 |
| **素点EV (Raw EV)** | 和了確率 × 打点 - 放銃確率 × 失点 による純粋な点数期待値。 |
| **順位EV (Placement EV / Pt EV)** | 局終了後の着順確率分布と順位点から算出される総合獲得ポイントの期待値。 |
| **オーラス逆転条件** | 南4局で着順を上げるために必要な和了打点（出和了・ツモ・直撃それぞれの条件）。 |
| **着落ち防衛** | 下位プレイヤーからの直撃やツモによって着順が下がるのを回避する守備基準。 |

## 3. 機能要件

### 3.1 機能一覧

| 要件ID | 機能名 | 概要 | 重要度 |
| :--- | :--- | :--- | :---: |
| `REQ-PLC-001` | 点況＆ルール設定基盤 | 4家のスコア、局数、本場、供託、順位点テーブルの管理 | **高 (P0)** |
| `REQ-PLC-002` | 順位EV (Pt EV) 算出エンジン | 打牌結果ごとのスコア変動から着順確率分布と順位Pt期待値を算出 | **高 (P0)** |
| `REQ-PLC-003` | オーラス条件逆算機能 | 逆転・着順アップに必要な翻・符・得点（出和了/ツモ/直撃）を自動計算 | **高 (P0)** |
| `REQ-PLC-004` | 点況適応型押し引き補正 | トップ目の局消化・放銃回避、ラス目の高打点狙いをEVと理由文に反映 | **高 (P0)** |
| `REQ-PLC-005` | 4人対局HUD点況統合 | `play_with_cpu.rs` の画面上に点差状況、Pt EV、条件ガイドを表示 | **高 (P0)** |

## 4. 非機能要件

- **応答性能**: 順位EVおよびオーラス条件の計算は打牌ごとに 1ms 未満で完了すること。
- **信頼性・正確性**: 麻雀の公式点数計算ルール・順位決定ルール（同点時の起家優先ルール等）に完全準拠すること。
- **テスタビリティ**: オーラス逆転条件計算、順位EV計算について単体テストを完備すること。
