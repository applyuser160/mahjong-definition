# ADR-0003: 点況判断・順位期待値（Placement EV）およびオーラス条件計算の設計方針

## ステータス
Accepted

## コンテキスト
現在の麻雀学習システムでは、各打牌の優劣を「素点期待値（和了点数 × 和了確率 - 放銃失点 × 放銃確率）」で評価していた。
しかし実際の半荘戦（東風戦・半荘戦）では、最終的な着順に応じた「順位点（ウマ・オカ）」の影響が極めて大きく、例えば以下のような点況に応じた戦術の使い分けが必須となる：
1. **トップ目**: 放銃失点リスクの極小化と速度重視による局消化。
2. **ラス目**: 安手によるあがり（意味のないアガリ）を避け、逆転に必要な打点を作る。
3. **オーラス**: 逆転に必要な点差を正確に計算し、ツモ・直撃・出和了の条件に応じた手作り・押し引きを行う。

これらを学習者に定量的に提示するため、順位期待値（Placement EV）および条件逆算エンジンのアーキテクチャを決定する必要がある。

## 決定事項
1. **順位点ルール構造体の柔軟性 (`RuleConfig`)**:
   - Mリーグ基準（+50 / +10 / -10 / -30、30,000点返し、オカ20）、連盟公式、天鳳順位戦ルールなど、一般的なルールセットを切り替え可能とする。
2. **高速・決定論的な順位確率予測モデル**:
   - ディープニューラルネットワークではなく、点差・残り局数・局結果（アガリ/放銃/横移動/流局）による点数変動からロジスティック分布/シグモイド関数近似を用いて高速（マイクロ秒単位）かつ決定論的に着順確率分布を算出する。
3. **オーラス逆転条件計算の明示化 (`TargetCondition`)**:
   - 直撃条件・ツモ条件・他家出和了条件を正確に算出し、学習者が「何翻何符が必要か」を一目で把握できるようにする。
4. **4人対局HUDへのリアルタイム統合**:
   - `play_with_cpu.rs` の画面上で、従来の素点EVに加え「順位Pt EV」および「点況アドバイス」を並行表示する。

## 影響とトレードオフ
- **メリット**:
  - 実戦麻雀において最も重要視される「着順意識」「オーラスの条件計算」をシステム上でリアルタイムに学習できるようになる。
  - マイクロ秒単位の高速計算により、対局体験を損なわない。
- **トレードオフ**:
  - 順位確率予測は数理近似に基づくため、極端な多局延長戦などの特殊ケースではわずかな誤差が生じる場合があるが、実戦学習ツールとしては十分な精度と説明性を確保できる。
