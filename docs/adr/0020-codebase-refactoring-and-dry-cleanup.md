# ADR 0020: 最適化機能群マージ後のコードベース健全化とリファクタリング

## 状態
承認 (Accepted)

## コンテキスト
Issue #104〜#109 のパフォーマンス改善PR（#110, #111, #112, #114, #115）が `main` にマージされた。
これにより向聴数計算・有効牌探索・役判定・API境界などの高速化が完了したが、`cargo clippy` の警告による CI 失敗や、各機能追加に伴うコードの重複（DRY違反）、不要な一時配列の使用といったコードスメルが存在していた。

## 決定
1. **Clippy 警告の解消**:
   - `clippy::needless_range_loop` を検知していたループを、スライス/配列のイテレータ（`.iter().enumerate()`）に置換する。
2. **`acceptance.rs` の DRY 化**:
   - 萬子・筒子・索子の 3 スーツで重複していた周辺牌マスク（$\pm 2$）の計算ロジックを、数牌スーツオフセットに基づく単一の純粋関数（`tile_neighbor_mask`）に統合する。
3. **`expectation.rs` の 1 パス化**:
   - `SafetyFeatures::from_context` において、一時配列 `[bool; 4]` を介さず `ctx.riichi_status` を 1 回のイテレーションで走査・集計する。
4. **同値性の担保**:
   - 全テスト（Rust・Python）の実行、Clippy および Rustfmt の通過を必須とし、動作および性能を維持する。

## 結果・影響
- `cargo clippy --all-targets -- -D warnings` が警告ゼロでパスする。
- 重複コードが削除され、可読性と保守性が向上する。
- 既存の全テスト・プロパティテストが 100% 同値で通過する。
